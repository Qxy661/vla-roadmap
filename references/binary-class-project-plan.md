# 二分类趣味教学项目 · 奶龙 vs 塔菲 方案

> 落盘日期：2026-08-01。MiniTorch 框架的趣味应用升级。

## 项目定位

- **目标**：把 MiniTorch（手写框架）+ PyTorch 用在**真实二分类任务**上
- **趣味**：奶龙 vs 塔菲（近期火的表情包形象）
- **务实**：先用公开数据（猫狗）跑通流程，再换趣味数据
- **教学**：对比手写框架 vs 框架，是"为什么用框架"的最佳教学

## 为什么二分类有意义

1. **最基础完整的 CV 闭环**：数据→训练→评估→识别
2. **验证 MiniTorch 在真实任务的表现**（不只是 CIFAR-10 基准）
3. **"形象分类"让人直观看到模型真的学会了"看"**
4. **对比教学**：同数据，MiniTorch vs PyTorch 差距一目了然

## 设计（两步走）

```
阶段1：猫狗二分类（公开数据，跑通闭环）
  - MiniTorch + PyTorch 各训一个（小模型+小数据子集，几分钟内完成）
  - 对比：准确率、训练速度
  - 打通：数据管线 → 训练 → 评估 → 识别脚本

阶段2：奶龙 vs 塔菲（趣味数据）
  - 数据换奶龙/塔菲图（各 100-200 张）
  - 微调/重训，做"识别奶龙还是塔菲"交互脚本
```

## 关键技术决策

1. **二分类输出**：1 个 logit + sigmoid（或 2 类 softmax）。框架已支持
2. **小模型 + 小子集**：避免纯 NumPy 训练过慢（50 分钟）。用 ~3000 张子集 + 小 CNN，几分钟内完成
3. **共用数据管线**：猫狗数据组织成文件夹结构，MiniTorch/PyTorch 共用
4. **对比记录**：同数据两框架的 acc/速度，写进教学文档

## 数据来源

- **阶段1**：公开猫狗数据集（如 kaggle cats-vs-dogs 子集，或 HuggingFace）
- **阶段2**：奶龙/塔菲图片（网络下载脚本 or 用户提供）

## 项目结构

```

```
