## 核心成果：两个关键洞察

### 1. MiniTorch 从零不输 PyTorch（重要发现）
- **同条件对比**：MiniTorch 0.543 vs PyTorch 0.500（无增强、从零、20ep）
- 手写框架（约 700 行 NumPy）在公平对比下**达到甚至略优于** PyTorch 从零
- **证明**：从零实现的原理（反向传播/卷积/BN/Adam）是完整正确的

### 2. 真正的差距在"生态"
- PyTorch + 预训练 ResNet18 微调 → **0.895**（迁移学习）
- 手写框架没有预训练生态 → 上限受限
- **结论**：MiniTorch 理解原理，PyTorch 高效出效果，两条路互补

## 关键工程经验

1. **BatchNorm 梯度爆炸 bug**：手写 BN 反向的 dx 公式错误，导致梯度放大 1e8 倍、模型学不动。用**数值梯度验证**定位，用**分步链式求导**重写修复。这是真实的"梯度爆炸"教学案例。
2. **框架能学 ≠ 数据够**：MiniTorch 在高对比人造数据 100% 收敛，但在真实猫狗只有 54%——数据量才是瓶颈。
3. **迁移学习是王道**：小数据下 frozen → 微调 → 判别性 lr 逐级提升（69%→78%→89.5%）。
4. **借鉴开源不闭门造车**：调研 torchvision/fastai/PyTorch 官方教程，采纳增强组合、判别性学习率、early stopping、适度增强原则。
5. **ROS 环境污染**：`scripts` 包名与 ROS 冲突，用 importlib 加载规避。
