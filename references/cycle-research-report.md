## 第二轮：GICP 具体实现（前端核心）

### 协方差计算
```
kNN(20) + PCA → 特征值改为 [1,1,ε]（ε=0.001，法向小）
源点协方差旋转：R·C·Rᵀ
```

### 残差与 Jacobian
```
残差 e = R·p + t - q（3×1）
权重 W = (C_q + R·C_p·Rᵀ)⁻¹（马氏距离）
Jacobian J = [-skew(Rp), I₃]（3×6）
更新：(H+μI)dx = -b，H=ΣJᵀWJ，b=ΣJᵀWe
旋转更新：指数映射 expm(skew(dθ))·R
```

### 关键
- GICP 统一了 point-to-point/plane（C=0 或 P⁻¹ 特例）
- 不一致patch → 弱约束（鲁棒性）

## 第三轮：位姿图优化（后端核心）

### g2o 格式
```
VERTEX_SE2 i x y theta
EDGE_SE2 i j x y theta info(3×3信息矩阵)
```

### 从零 5 步
```
1. 解析数据（g2o格式）
2. 建图（顶点pose + 边factor）
3. 误差函数 r = z⁻¹ ⊕ (x_i⁻¹ ⊕ x_j)
4. 线性化 + 稀疏Cholesky求解
5. 闭环检测（拉回漂移）
```

### 工具对比
- g2o+CHOLMOD 最快（M3500: 0.064s）
- GTSAM 增量（ISAM2）适合在线

## 第四轮：学习式路径规划（M5 P1）

### ERRT（Episodic RRT）完整实现
```
核心：SAC DRL 生成"探索片段"（代替随机点采样）
```

### 网络架构
```
输入：障碍(OBB/球) + 自身状态 + 目标
线性投影层（统一维度）→ 两层Transformer编码器
→ 1D max-pooling → 前馈网络 → 动作路径
```

### MDP
```
状态：自身 + 目标 + 局部障碍
动作：m个配置点的路径序列
奖励：路径长度 + 平滑 + 碰撞 + 到达 + 距离减少
```

### 性能（无GPU）
- 6D 机械臂：98% 成功率（vs RRT 19%），107× 快
- 碰撞检查减少 99.6%，路径短 50%

### 训练技巧
- 增量边界（防点集中）+ B样条重采样 + 集中采集

## 第五轮：视觉编码器微调 VLA（M3 P1）

### VLM4VLA 核心结论
```
冻结视觉编码器 = 灾难（-42分 Paligemma）
冻结词嵌入 ≈ 免费（±0.2分）
微调视觉编码器 = 最大杠杆（+18.1分）
```

### 动作监督微调（关键实验）
```
Qwen3VL-4B 视觉编码器 + FAST token（BridgeV2 数据）
基线27.6 → 动作监督45.7（+18.1）→ 再VLA 56.3→59.4
```

### 启示
- 小模型可胜大模型（Qwen3VL-2B > 30B）
- 通用 VLM 基准 ≠ VLA 性能
- 双编码器方案（冻结+可训练）替代方案

## 第六轮：MSFE 小目标检测（M2 P1）

### MSFE 方法（无需训练）
```
自适应引导切片（上阶段检测定位ROI）
→ 上采样（放大ROI子图）
→ 级联检测（后级检测器）
→ 结果合并
```

### 性能
- YOLO11-l +26.5% AP（VisDrone等4数据集）
- 优于 SAHI（性能+速度）和 ESOD（监督方法）

### 与 SAHI 对比
```
MSFE 用检测结果自适应切片（非固定窗口）
→ 更聚焦小目标 → 更快更准
```

## 第七轮：MPC 控制（M6）

### 差分驱动模型
```
状态 x=[x,y,v,θ]，控制 u=[a,w]
ẋ=v·cosθ, ẏ=v·sinθ, v̇=a, θ̇=w
```

### ACADOS 配置
```
N=30步, dt=0.2s, 控制频率20Hz（时域6s）
代价：NONLINEAR_LS（Gauss-Newton快）
权重：W=[100,100,50,1,1]（x,y,θ误差+控制）
约束：lbu/ubu + 障碍（椭圆/线性化/高斯）
```

### MPC vs PID（量化）
- 跟踪误差 0.04m vs 0.12m（3×优）
- 动态障碍：MPC 重规划，PID 卡住
