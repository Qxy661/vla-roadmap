## 关键决策与经验（重要，避免未来踩坑）

### 1. GPU 方案：PyPI 精简版 torch + 补 nvidia CUDA 库 = 等效 cu124
- **问题**：官方 cu124 torch（2.5GB）在你网络下下载卡死；PyPI 精简版（766MB）下完但缺 CUDA 库
- **解法**：装精简版 torch 2.6.0 + `nvidia-cudnn/cublas/runtime/nvrtc-cu12`（阿里云源），最终 `torch.__version__` 显示 `2.6.0+cu124`，**等效且省 2GB**
- **经验**：下载慢就换源，阿里云源 > 清华源 > 官方源（本网络环境实测）

### 2. starVLA 环境：复用 dl 环境（不隔离）
- starVLA requirements 的 torch 行是注释（`# torch==2.6.0+cu124`），非硬性
- `pyproject.toml` dependencies 为空，`pip install -e .` 不拖重依赖
- 故直接复用已配好 torch 的 dl 环境，省重复下载 3GB+

### 3. M0-5 范围收敛：框架可加载即验收，不下载 8GB 大模型
- 完整 QwenGR00T forward pass 需 Qwen3-VL-4B（8GB）+ flash-attn（编译）
- 判定：M0-5 验收 = 框架可加载/配置可解析/模块可导入
- 下载大模型 + flash-attn 编译 → **M3 前置任务**（训练时本来就要配）

## 踩坑记录

| 坑 | 表现 | 解法 |
|---|---|---|
| 清华源下载卡死 | miniconda.sh 0字节 / torch 卡 244M | 换阿里云源 / 官方源 |
| 嵌套引号地狱 | 多级 `wsl bash -lc` 变量被吞 | 复杂脚本用 Write 写文件再拷，不命令行 heredoc |
| PATH 含 Windows 括号 | `conda create` 语法错误 | 用 `source conda.sh` 激活，不手工拼 PATH |
| PyPI torch 缺 CUDA | `libcudart.so.12` 找不到 | 补装 nvidia-cudart 等 4 个库 |
| ROS2 无 `--version` | 健康检查误报失败 | 脚本改用 `--help` 判断 |
