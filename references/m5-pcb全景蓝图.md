# PCB 画板子全景蓝图（立创EDA）

> 从零基础到"能画飞控板/控制板"的完整路线图。
> 定位：控制硬件分支，软件主线（路径规划/控制）的物理落地。
> 工具：立创EDA（免费、元件库全、开源生态、嘉立创打样）。

## 一、全景总览

```
入门 → 原理图 → 封装库 → PCB布局布线 → 打样 → 焊接 → 飞控/控制板
```

**核心能力**：能设计一块"能工作"的PCB（原理图→布局→布线→生产）。

## 二、阶段详解（每阶段有产出+验收）

### 阶段0：入门准备（1周）
**内容**：装立创EDA专业版，熟悉界面，看官方Wiki
**产出**：能创建工程、放置元件、理解基本概念
**验收**：画出一个简单的LED闪烁电路原理图

### 阶段1：原理图设计（1周）
**内容**：元件放置、连线、网络标签、电源/地、DRC
**核心**：看懂数据手册，选对元件（立创EDA库全）
**产出**：MCU最小系统原理图
**验收**：原理图DRC无错，能转PCB

### 阶段2：元件符号 + 封装库（1周）
**内容**：手动画符号、封装（按手册尺寸）、关联
**核心**：库中没有的元件自己建（飞控常用IMU/稳压）
**验收**：能建一个元件（符号+封装+绑定）

### 阶段3：PCB布局布线（1-2周）
**内容**：转PCB、板框、布局（先大后小/按飞线）、手动布线、铺铜/泪滴、DRC
**核心规范**：电源线加粗、135°拐角、晶振靠近MCU、GND铺铜
**验收**：STM32最小系统板布局布线完成，DRC无错

### 阶段4：生产输出（几天）
**内容**：Gerber导出、BOM、嘉立创下单
**核心**：免费打样（≤10cm×10cm），新手友好
**验收**：板子下单成功，能拿到实物

### 阶段5：焊接调试（1周）
**内容**：焊板、上电、调试、排查
**核心**：学会焊接（SMD/直插），用万用表排查
**验收**：板子能工作（LED亮/程序跑通）

## 四、目标板设计要素（调研总结）

### 小车/机器人控制板
```
主控：STM32 / ESP32
电机驱动：H桥 / 栅极驱动 + MOSFET（大电流）
供电：电池 → 稳压(5V/3.3V) → MCU
接口：PWM/串口/I2C/电机接口
关键：电源线宽≥1.5mm，电机电流裕量
```

### 无人机飞控板
```
主控：STM32F405（FPU/DSP）
传感器：MPU6050 IMU + 气压计
电源：LC滤波 + 稳压（独立LDO给IMU）
布局：IMU放中心、晶振靠近MCU、地过孔隔离
层数：4层（信号/GND/电源/信号）
```

## 八、调研补充：关键设计细节（可执行）

> 基于调研（STM32最小系统教程、飞控板四层PCB规范）补充的落地细节。

### 8.1 STM32 最小系统板（第一个目标板）元件清单

| 模块 | 元件 | 要点 |
|---|---|---|
| MCU | STM32F103C8T6 / F407 | 优先选立创商城编号 |
| 电源 | AMS1117-3.3 | 5V→3.3V，输入输出各滤波电容 |
| 晶振 | 8MHz 无源 | 匹配电容按数据手册（负载12pF→两个18pF）|
| 复位 | 10kΩ + 0.1μF + 按键 | RC复位电路 |
| 去耦 | 每VDD引脚 0.1μF | 就近放置 |
| 下载 | SWD 4针（SWDIO/SWCLK/GND/3.3V）| ST-Link |
| BOOT | BOOT0/BOOT1 下拉 | 从Flash启动 |

**选型原则**：优先 LCSC 立创商城编号（购买方便 + 封装可靠）

### 8.2 小车/机器人控制板设计要点

**电源树**：
```
电池 → 防反接/TVS → DCDC(5V/12V) → 3.3V LDO → MCU
                                    ↘ 电机驱动
```

**电机驱动**：H桥 / 栅极驱动 + MOSFET，大电流路径 2oz 铜厚、线宽≥2mm

**关键**：
- 电机地 与 逻辑地 分开（单点连接）
- 电源线短粗直（星型拓扑）
- PWM 输出串联 220Ω 或 RC 滤波

### 8.3 无人机飞控板（四层板）设计规范

**叠层**：Top(信号) → L2(GND整面) → L3(PWR按域分割) → Bottom(信号)

**EMC 三要点**：
1. **电调干扰**：栅驱走线≤5mm、10Ω+TVS+共模扼流圈
2. **IMU 模拟域**：独立LDO（纹波<50µV）、I2C内层+包地
3. **射频**：天线50Ω微带、GPS离电机≥20mm

**IMU 布局**：PCB几何中心、下方整面地、独立LDO、guard ring

**电源树**：
```
电池(2-6S) → 防反接/TVS → DCDC(5V) → 3.3V LDO → IMU专属LDO
```

**验证**：电源纹波≤50mV、静止时加速度计波动<0.01g、近场探头自扫

### 8.4 布线与 DFM 通用规范

| 项 | 规范 |
|---|---|
| 信号线 | 0.2-0.3mm |
| 电源线 | 1A≈1mm（控制板0.5-0.8mm）|
| 转角 | 45°或圆弧，禁直角 |
| 间距 | 0.2-0.3mm |
| 过孔 | 内0.3/外0.6mm |
| 覆铜 | GND大面积铺铜 |
| 晶振 | 靠近MCU≤10mm，下方铺地 |

## 九、小车控制板详细方案（调研补充）

### 9.1 推荐架构（STM32 智能小车）
```
7.4V电池(18650x2) → LM2596降压(5V) → AMS1117(3.3V)
                                    ↘ MCU + 传感器
MCU(STM32F103) → 电机驱动(TB6612) → 直流电机
MCU → 传感器(循迹/超声波) + 通信(蓝牙)
```

### 9.2 电机驱动选型：TB6612 vs L298N

| 维度 | TB6612FNG | L298N |
|---|---|---|
| 电压 | 2.5-13.5V | 4.5-46V |
| 电流 | 1.2A/通道 | 2A(需散热) |
| 压降 | ~0.5V | ~2V |
| 发热 | 低 | 高 |
| 推荐 | ✅ 首选 | 不推荐 |

**结论**：TB6612（MOSFET 方案，低压降低发热，PWM 高频）
**替代**：DRV8833 / DRV8848（TB6612 有假货/停产风险）

### 9.3 电机驱动接线（TB6612）
```
PWM_A/PWM_B → STM32 定时器PWM（速度）
AIN1/AIN2/BIN1/BIN2 → STM32 GPIO（方向）
STBY → GPIO（使能，必须高）
OUT1/OUT2 → 电机
VM → 电池/电机电源
GND → 与MCU共地（必须）
```

### 9.4 电源设计要点
- 电池入口：防反接二极管 + 0.1μF去耦
- **电机电源与逻辑电源隔离**（0Ω或磁珠单点连接）
- 电机驱动旁：100μF电解 + 104陶瓷
- 大电流路径线宽≥1.2mm，铺铜

### 9.5 布局要点
- MCU 居中（走线短）
- 电机驱动靠近电机接口（大电流路径短）
- 电源模块远离敏感信号（晶振/传感器）
- 功能分区：电源驱动区 / 数字区 / 传感器区
