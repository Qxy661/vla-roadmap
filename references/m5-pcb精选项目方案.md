# PCB 精选复杂项目方案（作品集落地）

> 基于调研（《电子线路板设计实用教程》2025、OSHWHub开源项目、嘉立创全流程）。
> 理念：知识概念 + 全流程闭环可落地实践 + 精选高设计度复杂项目。

## 一、核心洞察（调研学习）

1. **完整闭环项目** = 原理图→布局→布线→DRC→Gerber→打样→焊接→调试
2. **精选高设计度** = 有真实功能的板（控制板/飞控），不是 LED demo
3. **可落地** = 嘉立创免费打样 + LCSC 元件 + 完整流程

## 三、精选复杂项目设计

### 精选项目：小车控制板（STM32 + 电机驱动）

**设计度**：★★★★（功能真实、电路完整、可实际运行）

**功能**：
- STM32F103C8T6 主控（PWM 控制电机）
- TB6612 电机驱动（双电机差速）
- 电源（7.4V电池 → 5V → 3.3V）
- 接口（SWD下载 / 传感器 / 蓝牙）

**电路模块**：
| 模块 | 内容 |
|---|---|
| MCU最小系统 | 晶振/复位/BOOT/SWD/去耦 |
| 电机驱动 | TB6612 + 隔离 |
| 电源 | LM2596(5V) + AMS1117(3.3V) |
| 接口 | 电机/传感器/通信 |

**闭环**：原理图 → PCB → Gerber → **打样** → 焊接 → **调试运行**

### 进阶项目：飞控板（后续，M7 关联）

**设计度**：★★★★★（四层板 + EMC + IMU）

**要素**：STM32F405 + MPU6050 + 四层板 + EMC规范
**参考**：《电子线路板设计实用教程》（CH32V103 飞控全流程）

## 四、全流程闭环执行计划

```
阶段A 学习基础（1-2周）
  安装立创EDA专业版 + 教程入门
  → 产出：掌握原理图/布局/布线基础

阶段B 入门项目（1周）
  LED调光板（USB-C + LDO + PWM）
  → 产出：第一块板打样成功

阶段C 进阶项目（1-2周）
  STM32最小系统板
  → 产出：MCU核心板打样+点亮

阶段D 精选项目（2-3周）
  小车控制板（STM32 + TB6612）
  → 产出：控制板实物 + 小车跑起来

阶段E 作品集（1周）
  知识文档 + 实物照片 + 调试记录
  → 产出：PCB 独立模块完整
```

## 五、与主线协同

```
M5 路径规划(软件) ←→ PCB(硬件)
  控制算法 → 控制板执行
  巡检小车 → 小车控制板

M6 控制(软件) → 控制板(硬件) → 真车执行

```

**价值**：软件能力（算法/控制）+ 硬件能力（PCB/实物）双全 → 完整工程师

## 六、验收标准

1. 完成 LED → STM32 → 小车控制板三个项目
2. 每块板：原理图 + PCB + 打样 + 实物 + 调试
3. 小车控制板能实际驱动小车（全流程闭环）
4. 知识文档 + 作品集完整
