## 二、调研结论（方案依据）

### 算法库范围（权威框架）
| 类 | 算法 | 必要性 |
|---|---|---|
| 图搜索 | Dijkstra / A* / D* | 核心 |
| 采样 | RRT / RRT* / PRM | 核心 |
| 局部 | DWA / TEB | 核心 |

**不贪多**：权威综述确认"图搜索+采样+局部"是三大类。智能算法（遗传/蚁群）科研少用于导航，不纳入。

### MATLAB 角色（科研验证）
- **MATLAB** = 算法设计/原型/数学验证工具
- **Nav2** = 部署标准
- **用法**：同一算法三种实现对比（Python手写/MATLAB/Nav2），体现科研严谨性

### 全流程闭环
```
建图(SLAM) → 定位(AMCL) → 全局(A*) → 局部(DWA) → 控制
```
