# 路径规划知识图谱 · 从算法到体系到应用

> 目标：真做导航的应用能力 + 科研能力。从"只知道算法"进阶到"体系认知到实际应用"。
> 三层结构：算法认知 → 体系认知 → 应用认知。

## 核心思维转变

```
之前：路径规划 = A* / RRT / DWA（一堆算法）
现在：路径规划 = 导航系统的一个环节，算法是零件
```

## 第一层：算法认知

### 全局规划（已知地图，离线）

| 算法 | 原理 | 特点 | 适用 |
|---|---|---|---|
| **Dijkstra** | 最短路，无启发式 | 最优但慢 | 小图，无条件 |
| **A*** | Dijkstra + 启发式 f=g+h | 最优且快 | 静态地图（最常用）|
| **D*/D*Lite** | 动态重规划 | 增量更新 | 环境变化 |
| **RRT** | 随机采样树 | 快，不最优 | 高维/动态 |
| **RRT*** | RRT + rewiring | 渐近最优 | 高质量路径 |
| **PRM** | 预采样路图 | 多查询 | 重复规划 |

**核心取舍**：
- A*：已知静态图 + 要最优 → 图搜索
- RRT：高维/难建模 → 采样，快但不最优
- 选哪个？看"地图是否已知、要不要最优、维度多高"

### 局部规划（在线，实时避障）

| 算法 | 原理 | 特点 |
|---|---|---|
| **DWA** | 速度空间采样 | 实时，常用 |
| **TEB** | 时间弹性带优化 | 平滑，考虑约束 |
| **MPC** | 模型预测控制 | 最优，计算大 |

**核心**：局部规划吃实时传感器数据，输出速度指令，负责避障。

### 算法关键认知（不是背，是懂取舍）
1. **全局给方向，局部给速度**——两者配合
2. **A* 最优但假设地图已知**；真实环境地图在变
3. **DWA 是"下位"算法**（跟随全局路径并避障）
4. 科研关注：最优性/完备性/复杂度/动态性

## 第二层：体系认知（算法 → 导航系统）

```
完整导航系统（不是单算法）
├── 建图 SLAM：怎么得到地图
│   ├── 激光 SLAM（slam_toolbox/Cartographer）
│   └── 栅格地图表示
├── 定位 AMCL：怎么知道"我在哪"
│   └── 粒子滤波（激光匹配）
├── 全局规划：怎么走（A* 在全局地图）
├── 局部规划：怎么避障（DWA 实时）
└── 控制：怎么执行（PID/MPC 跟踪轨迹）
```

**关键认知**：算法在系统里的**位置**比算法本身重要。
- A* 只是"全局规划器"一个零件
- 真正导航是"建图→定位→全局→局部→控制"闭环

## 第三层：应用认知（系统 → 真做导航）

### MATLAB 仿真 vs 实际部署（你的核心疑问）

| | MATLAB 仿真 | ROS2 实际部署 |
|---|---|---|
| 算法 | 内置 Toolbox | Nav2 栈 / 手写 |
| 地图 | 理想已知 | 激光实时建 |
| 定位 | 假设已知 | AMCL 实时算 |
| 输出 | 路径图 | 控制指令 |
| 本质 | 算法验证 | 完整系统 |

### ROS2/Nav2 实际导航流程

```
激光雷达 → SLAM建图 → 栅格地图
目标点 → AMCL定位(我在哪) → 全局A*路径
        → 局部DWA避障 → 控制底盘执行
```


## 五、科研方向（就业/学术能力）

1. **算法改进**：A*变体（跳点搜索）、RRT*变体（informed-RRT*）
2. **多约束**：动力学约束规划（Dubins/Reeds-Shepp）
3. **动态环境**：D*Lite、MPC 重规划
4. **融合**：深度学习+规划（learning-based planning）
5. **评估**：路径长度/平滑度/计算时间/成功率
