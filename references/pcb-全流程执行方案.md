# PCB 全流程执行方案（实施版）

> 落盘：2026-08-03。供审核后实施。
> 目标：从零基础到完成小车控制板（精选项目），全流程闭环。

## 一、总览

```
阶段A 环境准备 → 阶段B 入门项目 → 阶段C 进阶项目 → 阶段D 精选项目 → 阶段E 作品集
(装软件+学基础) (LED调光板)     (STM32最小系统)  (小车控制板)    (文档+展示)
```

## 二、阶段A：环境准备（第1周）

### A1 安装工具
- [ ] 注册立创EDA账号（在线版即可，后续用专业版）
- [ ] 下载安装**立创EDA专业版**（pro.lceda.cn）
- [ ] 下载嘉立创下单助手（打样用）

### A2 学习基础（选看）
- [ ] 官方Wiki：PCB设计全流程教程
- [ ] B站"国一学长"入门篇（第1-2讲：界面+原理图基础）
- [ ] 看懂欧姆定律、元件符号（电阻/电容/LED/芯片）

### A3 验收
- [ ] 能创建工程 + 放置元件 + 连线
- [ ] 画出最简单的 LED 电路原理图

## 三、阶段B：入门项目 - LED调光板（第2周）

### B1 设计
- [ ] Type-C 接口 + LDO(5V→3.3V) + PWM调光 + LED
- [ ] 原理图设计（参考官方Wiki Type-C教程）
- [ ] DRC 检查

### B2 PCB
- [ ] 原理图转PCB → 板框(≤10cm×10cm) → 布局 → 布线
- [ ] 铺铜 + 泪滴 + DRC

### B3 生产
- [ ] 导出 Gerber + BOM
- [ ] 嘉立创下单打样（免费）

### B4 验收
- [ ] 板子实物到手 + LED 能亮（全流程跑通）

## 四、阶段C：进阶项目 - STM32最小系统板（第3-4周）

### C1 设计
- [ ] STM32F103C8T6 + 晶振 + 复位 + BOOT + SWD + 去耦
- [ ] 电源（USB/LDO 3.3V）
- [ ] 原理图设计（参考《电路设计与制作实用教程》）
- [ ] DRC

### C2 PCB
- [ ] 布局（MCU居中、晶振靠近、去耦就近）
- [ ] 布线（电源加粗、45°转角、GND铺铜）
- [ ] DRC 0错误

### C3 生产+调试
- [ ] Gerber → 打样
- [ ] 焊接 → 上电 → 用 ST-Link 烧录 LED 测试
- [ ] **验收：程序跑通（最小系统工作）**

## 五、阶段D：精选项目 - 小车控制板（第5-7周）

### D1 电路设计
- [ ] **STM32F103 + TB6612 电机驱动 + 电源树 + 接口**
- [ ] 模块：MCU最小系统 / 电机驱动 / 电源(7.4V→5V→3.3V) / SWD/传感器/蓝牙
- [ ] 原理图设计（参考 OSHWHub 智能小车开源项目）
- [ ] DRC/ERC

### D2 PCB（高设计度）
- [ ] 功能分区（功率区/数字区/传感器区）
- [ ] 电源线≥1.5mm，电机地与逻辑地隔离
- [ ] TB6612 靠近电机接口
- [ ] DRC 0错误

### D3 生产+调试（闭环关键）
- [ ] Gerber + BOM → 打样（嘉立创）
- [ ] 焊接（先贴片后插件）
- [ ] 分模块调试：电源→烧录→电机→传感器→蓝牙
- [ ] **验收：小车实际跑起来（全流程闭环）**

## 六、阶段E：作品集（第8周）

- [ ] 知识文档（docs 4篇：基础/原理图/布局/生产）
- [ ] 实物照片（3块板）+ PCB 图
- [ ] 调试记录（遇到的问题+解决）
- [ ] 创建 `pcb-design` 仓库推送
- [ ] 链接库（resources/）

## 七、时间线（总计约 8 周）

| 周 | 阶段 | 产出 |
|---|---|---|
| 1 | A 环境 | 立创EDA就绪 |
| 2 | B 入门 | LED调光板实物 |
| 3-4 | C 进阶 | STM32最小系统跑通 |
| 5-7 | D 精选 | 小车控制板跑车 |
| 8 | E 作品集 | pcb-design仓库 |

## 八、验收总标准

1. 3 块板完成（LED/STM32/小车控制板），都有实物
2. 小车控制板能实际驱动小车（全流程闭环）
3. 每块板有原理图+PCB+实物+调试记录
4. pcb-design 作品集仓库完整推送

## 九、风险与应对

| 风险 | 应对 |
|---|---|
| 元件买不到 | 优先 LCSC 编号，有库存的 |
| 打样失误 | 每月2次免费，可重打 |
| 焊接失败 | 分模块调试，先易后难 |
| 设计错误 | DRC/ERC 双检查，参考开源 |
