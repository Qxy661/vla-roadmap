# 作品集结构规划

> 重心：知识概念 + 全流程闭环落地能力 + 精选高设计度复杂项目。
> 方案：一个导航仓库 + 多个独立项目仓库（方案B），每个项目体现"概念→闭环→落地"。

## 一、核心理念（贯穿所有项目）

```
每个项目 = 知识概念(教程) + 全流程闭环(方法论) + 精选复杂项目(落地)
```

- **知识概念**：教学文档（讲原理，建立认知）
- **闭环能力**：数据→训练→评估→部署 / 算法→体系→应用
- **复杂项目**：精选的、有设计深度的完整项目（不是 demo）

## 二、作品集总结构

```

│   └── path-planning       ← 概念(6篇知识体系) + 闭环(算法→MATLAB→Nav2) + 巡检
```

## 三、每个项目的统一结构（规范）

```
<项目名>/
├── README.md            # 门面：定位/成果/方法论
├── docs/                # 知识概念（教学文档）
│   ├── 01-...（原理）
│   └── ...
├── TECHNICAL_SUMMARY.md # 技术总结（展示态）
├── <核心代码>/          # 全流程闭环实现
├── results/             # 成果图/指标
└── LICENSE              # MIT
```

## 五、精选复杂项目（高设计度，作品集亮点）
